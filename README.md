# Spice Kitchen — JW Marriott Pune

A responsive, framework-free restaurant website concept based on the information supplied in the restaurant listing. The chef film is included at `assets/spice-kitchen-film.mp4`, trimmed to end before the sidebar appears, and remains a single fixed background across the page. Video time is controlled by page scroll and remains paused otherwise.

## Preview

Open `index.html` in a modern browser. For reliable video seeking, serve the folder over a local HTTP server (for example, `python -m http.server 8000`) and visit `http://localhost:8000`.

## Included

- All-day dining, buffet service, Sunday brunch, and à la carte information
- User-provided listing snapshot: 4.9 rating and 2,855 reviews
- Address, opening hours, dietary options, parking, valet, and phone links
- Smooth anchor navigation, scroll progress, reveal animations, and reduced-motion support
- No framework or install step required; Google Fonts load remotely with local system fallbacks

The page is a front-end concept. Confirm listing details before publishing. Phone links place a call; no online reservation or menu backend is connected.
